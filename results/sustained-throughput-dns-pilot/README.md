# DNS 异常环境预跑（中断）

这是首次持续负载尝试，未完成，不作为正式模型吞吐比较。

客户端当时使用 aiohttp 默认短期 DNS 缓存。运行中单独测量系统 `socket.getaddrinfo`，JEV API 域名解析分别耗时 30.004 秒（AF_INET、AF_UNSPEC），Flash 均约 0.005 秒。部分请求因此可能撞上 10 秒连接超时。该诊断解释了一个明确的客户端环境干扰，不能证明所有错误都来自 DNS。

运行通过 SIGINT 中断；已完成档的原始响应、配置、摘要及冻结脚本保留，活动档尚未写出的响应和费用没有完整归档。不得将这批数据与后续正式结果合并。

后续正式测试先通过系统解析器取得各 API 域名的地址，在整轮测试内复用相同解析结果，保留域名与 TLS 校验；两模型执行相同规则。连接池闲置复用时间调整为 aiohttp 默认的 15 秒，并记录超时异常类型。测试矩阵、题目、金标及评分不变。
