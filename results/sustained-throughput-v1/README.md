# 持续多题并发结果

正式负载请求 29,537 次，校准请求 62 次；44 / 56 个计划窗口纳入汇总。已知用量按高峰价累计 $5.9994；缺失用量未作零费用解释。

[测试协议](../../docs/SUSTAINED_THROUGHPUT.md) · [配置](config.json) · [汇总](comparison.json) · [逐档统计](summary.json) · [完整性清单](archive_manifest.json)

每请求 8 道医疗题，工作器持续补入，5 秒预热后统计 30 秒，重复两轮。200 题分流板为单独的非医疗工程测试。实际并发可能受服务配额约束；这些结果不是模型吞吐上限或全天稳定性证明。

两模型在校准前完成系统 DNS 解析，整轮复用解析结果；查询耗时另存于 dns-*.json。此前因 DNS 延迟中断的环境预跑单独保留，未混入本轮统计。格式错误与选项错误均影响端到端准确率，不能把二者全部归因于医学推理能力；汇总 JSON 另列合法选项比例及合法项中的准确率。
