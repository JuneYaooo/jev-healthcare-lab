# Jev Healthcare Lab

Jev 在医疗文本、病历结构化、患者入组预筛和循证核查中的应用研究与可审计实验。非 TypeSafe 官方项目。

本仓库关注“哪些步骤值得交给 Jev，以及在哪里失败”。当前是探索性离线评测，不是可用于自主诊疗的产品。

## 实验快照

2026-09-24，固定 `jev-1.13.0`：**6,586 条医疗评测 + 300 条配对鲁棒性评测**。其中 43 条无候选记录由程序输出空预测，剩余 6,843 条有真实 API 响应。记录包含重复病例的多个条件，不是独立患者数。

| 实验 | 结果 | 解释 |
|---|---|---|
| medspaCy → Jev 实体筛选 | 严格 F1 58.9% → 69.4% | 减少误报，但召回率仍只有 61.7% |
| MedHallu 医学幻觉识别 | 无证据 60%，有证据 82% | 同批问题配对，不能代替检索评价 |
| TrialGPT 数据直接三分类 | 150 条，48% | 不支持自动剔除或确认入组 |
| BMI 候选参数 + 程序公式 | 正确参数对 17/20 | 不是所有临床计算器的性能 |
| MedCalc Verified 有界评分 | 100 条，25% | 5种评分的闭集适配，不是完整基准 |

90 项资源清单包含数据集、赛事和工具；39 项入口有有限样本实测映射，存在重叠，不能按入口数量累加样本。

## 快速检查（无需密钥、无需下载数据）

```sh
python3 scripts/summary.py
python3 -m unittest discover -s tests -v
```

`results/` 提供历史汇总和不含原文的评测索引。`scripts/` 提供候选构造、Jev调用、评分和少量上游OCR/ASR适配代码。运行真实评测前需自行取得数据，详见复现说明。

## 目录

```text
docs/       调研、方法、患者入组专题与限制
scripts/    数据适配、真实API调用、评分代码
results/    2026-09-24聚合结果与样本身份/哈希
examples/   人工构造的接口示例
tests/      无外部服务依赖的仓库与指标检查
```

原始病历、基准全文、音视频、模型权重、凭据与运行缓存不上传。数据授权与第三方许可独立于本仓库代码许可。原联合研究中自媒体与医疗分开评分；本仓库不包含自媒体任务代码。

同系列项目：**Jev Media Lab**，研究评论审核、情绪/立场、赞助字幕与创作者工作流。
