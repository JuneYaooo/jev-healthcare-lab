# 医疗决策评测方法

v0.6.0 含 59 个有题任务、5,594 题；51 个任务各 100 题，8 个为不足量的探索性任务。开放核心集 4,051 题，非商业研究附加集 1,543 题；另 18 个任务为空。当前没有本版本的模型成绩。

## 输入与输出

模型只接收每题的 `request`，需要时按服务接口添加模型名。`state` 是材料，`questions.decision.criteria` 是候选选项。不得把 `gold`、来源标注或适配元数据作为模型输入。

预测 JSONL 每行包含 `id` 和 `choice`，或 `id` 与 `response.answers.decision.choice`。题号必须与数据集完全一致。缺失回答、无效选项、格式错误回答都按错计；重复或未知题号使计分失败。两种预测结构不得用于重复提交同一题。

## 指标与汇总

- 逐任务：准确率、宏 F1、逐类召回、来源组全对率。
- 场景汇总：同场景内各任务准确率等权平均。
- 主汇总 `scenario_macro_accuracy`：有题场景等权平均。
- 空场景：分数为 `null`，不按零分处理，同时展示覆盖率。
- 分层：语种、来源性质、决策阶段、决策模式、原始划分、样本数量完整性和历史材料匹配状态。

宏 F1 按实际有金标的类别计算，未出现的候选类别单列。能力标签允许重叠，只用于分层，不累加为主分母。默认评分范围为开放核心集；需要完整范围时显式开启研究附加集。不同覆盖范围的分数不能直接比较。

## 抽样与来源组

从固定版本解析原标注，以声明的标签、量表或来源等分层抽样，固定种子为 20261010。先尽量每来源组一题，再按规则放宽到每组最多五题。去除重复请求、冲突答案、不能可靠解析的标注和冻结本地训练指纹命中。数量不足时保留实际数量，不改写或复制补题。

`group_id` 表示来源文档、句子、模拟病例或患者组，不保证一律是患者。LongHealth 的 100 题只来自 20 个虚构患者；各任务之间也可能共享材料。比较模型或训练前后差异时应使用相同题目、选项、提示与评分范围，并按来源组配对或聚类分析，不能把共享文档内的题目都当成独立患者。

UCI 结局预测按其声明的自然分布抽样；新增脓毒症任务按标签分层抽样，改变了类别比例。分诊、考试和材料任务按各自规则抽样。小样本任务不宜与完整任务的精度等同看待，另看 `sample_completeness` 分层。详细协议见 [v0.4.0 扩展](EXPANSION_V040.md)。关系选择中的实体 ID 不是跨病例医学类别，其宏 F1 不作临床类别指标解释。

## 暴露与适用范围

已保留冻结筛查索引和逐题暴露标记。当前题目没有命中该索引内的训练指纹；577 题材料或片段命中过往评测指纹，通用片段可能造成误报。该检查不能证明不存在翻译、改写、患者级关联或基础模型预训练暴露。

其中 353 题原属上游公开训练划分（中文 CMB 253 题、PhysioNet 100 题），已标记并提供 `upstream_split` 分层；若模型训练使用过这些数据，应单独剔除或报告，不能称为盲测。

用于评测训练效果时，应将本集隔离于训练数据；不要根据测试分数挑换题目。每任务 100 题适合初步固定对照，尚不足以确认细小改进或临床有效性。当前评分是描述性统计，没有自动计算显著性或置信区间。

来源含公开病例报告、临床材料、考试改编和模拟病例，各自性质逐题记录。答案来自上游标注与机械映射，尚无本项目独立医生逐题审核；场景覆盖也不表示完整临床工作流能力。

## v0.5.0 新任务的解释范围

脓毒症固定时点预测采用公开训练来源自留子集，11 个阳性、89 个阴性。至少同时报告两类召回；恒答阴性的准确率为 89%，不作为临床性能证据。该目标不同于原挑战逐小时 utility，不能与其排行榜直接比较。隐私任务是给定词判断，不能报告为全文脱敏召回；参考区间任务是给定资料条件匹配，不能报告为独立诊疗知识正确率。详见 [适配协议与限制](GAP_AUDIT_V050.md)。

## v0.6.0 新任务的解释范围

CPIC 是固定指南规则评测，功能表型 84 题仅覆盖 19 个基因；用药建议 100 题覆盖 25 个指南。应报告来源组，且不能将候选 ID 的宏 F1 解释为统一医学类别指标。LabQAR 判读使用给定区间和作者构造数值。Evidence Inference 判断比较试验报告的效果方向，不直接选择最佳治疗；其 100 题来自 100 篇文章。前版所有 5,210 条完整记录保留，可按 ID 使用相同子集比较。详见 [适配协议](EXPANSION_V060.md)。
