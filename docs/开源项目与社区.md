# Jev 社区：医疗与自媒体分开核查

检索时间：2026-09-24。采用官方文档、项目源码/README和原帖；社区目录仅用于发现线索。仓库存在、演示可运行、作者报告成绩、独立真实调用、医院临床验证是不同层次。本轮没有复现下面所有完整应用，也没有证据证明某个产品方向“全世界没人做”。

## 医疗：直接使用 Jev 的项目和研究

| 项目 | 正在做什么 | 可确认程度与限制 |
|---|---|---|
| [PulseLane](https://github.com/ndolinschi/pulselane) | 门诊分诊判断界面，接TypeSafe；无key时使用启发式演示 | README明确有演示回退；不应把网页演示当模型结果或临床验证。未运行完整应用 |
| [jev-korean-benchmark](https://github.com/mahlernim/jev-korean-benchmark) | 韩英理解、医学考试及输入顺序的可复现样本检查 | 作者披露100题/条件、小样本与公开题污染限制；医学题与语言配对实验分开。属于独立作者报告，本轮未重跑其全套 |
| [jev-jmle-benchmark](https://github.com/kokuren333/jev-jmle-benchmark) | 日本医师考试的选择题、信息充分性、校准和选择性预测 | 作者报告3,556题、exact-set 88.58%；未提供图像，非临床能力验证。本轮不把其成绩并入自己的样本 |
| [jev-scientific-development](https://github.com/vafaei-ar/jev-scientific-development) | 论文/研究计划评审、写作审计、质疑论断的工具 | 科研判断脚手架；不是已验证的医疗决策系统 |
| [PRomop](https://github.com/healthkey-ai/promop) | FHIR→OMOP患者记录、概念映射、试验匹配所需的结构化投影 | 基础项目可确认；目录收录了作者[“now with Jev”概念映射帖子](https://x.com/adamblum/status/2100888391889883564)，但X原页读取失败，本轮未确认具体Jev提交，因此仅列待核实集成线索 |

不能把名字含triage的所有项目都归入医疗：[jev-triage](https://github.com/ThyFriendlyFox/jev-triage)属于通用判断/主动学习路线，本轮没有把它算作临床分诊落地。

医疗开源替代栈包括[medspaCy](https://github.com/medspacy/medspacy)、[EDS-NLP](https://github.com/aphp/edsnlp)、[EDS-Pseudo](https://github.com/aphp/eds-pseudo)、[medkit](https://github.com/medkit-lib/medkit)、[LangExtract](https://github.com/google/langextract)、[DeepPhe](https://github.com/DeepPhe/DeepPhe-Stream)。它们可以承担候选抽取、否定词、去标识化、证据回链等环节，并不是Jev原生项目。本轮真实运行了medspaCy词典实体抽取基线，其他工具仅调研，未伪称安装测试完成。

## Reddit 与 X：区分原帖、作者数字和二手线索

[Reddit的1,759次判断评测帖](https://www.reddit.com/r/LLMDevs/comments/1wo000s/we_benchmarked_typesafes_new_jev_a_decisiononly/)声称Jev在作者任务上接近更大模型且成本更低。这些是作者报告，任务、模型、网络和统计口径不同，不能转用为本轮医疗准确率或降本比例。[另一个路由实践帖](https://www.reddit.com/r/LLMDevs/comments/1wihigc/tried_typesafes_new_decisiononly_model_jev_as_an/)也属于路由用途经验，不能说明自动诊断有效。

[daftAI2026目录](https://github.com/daftai2026/awesome-jev)快照的X数据文件含400条条目，本轮用关键词筛出相关线索。目录自身也注明X与YouTube条目独立存放。400条不是本轮逐条读取的X原帖；不能据此概括用户共识、活跃人数或采纳率。HealthKey帖子原页未能直接读取，因此保留待核实状态。

[TypeSafe文档](https://docs.typesafe.ai/models)给出模型与价格；[confidence说明](https://docs.typesafe.ai/confidence)和[模型局限说明](https://docs.typesafe.ai/model-jaggedness/jev-1.13)应与社区演示一起阅读。固定候选决策、概率输出和低单次费用是接口特点，不意味着任何领域都高准确。
