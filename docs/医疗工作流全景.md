# 医疗工作流全景与覆盖边界

本表是业务场景地图，不是每行都完成了真实医院验证。本轮已扩展至多个公开数据适配任务、24类人工挑战以及真实OCR/ASR小规模链路；当前数量、成绩和未完成项以《研究报告.md》《结果总表.md》《覆盖与阻塞账本.md》为准。

## 2. 高频流程地图

下面的优先级是依据可验证性、错误后果和集成复杂度作出的产品判断，尚无医院工时实验支撑。“高频”指多数记录或消息反复需要处理，不代表已统计某医院日均业务量。

| 环节 | 可做的具体判断 | Jev 外还需要什么 | 应衡量的收益 | 优先级 |
|---|---|---|---|---|
| 就诊前 | 咨询意图、预约/报告/药物问题分流 | 科室与业务目录、人工接管 | 每消息处理秒数、错转率 | 高 |
| 就诊前 | 主诉归类、既往史与现病史区分 | 实体召回、原文证据 | 录入时间与字段修订率 | 高 |
| 就诊前 | 是否缺少年龄、持续时间等采集项 | 已批准的专科问卷 | 补问次数、完整率 | 高 |
| 分诊 | 紧急程度、红旗症状提示 | 临床规则、专科验证、人工流程 | 高风险漏检率；不能只报accuracy | 后置 |
| 接诊 | 症状/体征/检查/药物实体筛选 | 词典、NER或候选片段生成器 | 严格边界F1、复核工时 | 高 |
| 接诊 | 肯定、否定、未知、疑似 | 全文语境与作用范围 | 否定类召回、错误阳性率 | 高 |
| 接诊 | 患者本人/家属、当前/历史 | 指代、时间候选 | 主体和时态错填率 | 高 |
| 接诊 | 诊断/症状同义词映射标准词 | 标准术语库和检索器 | 候选Recall@K、最终映射准确率 | 高 |
| 接诊 | 病历章节归类、文本归档 | 稳定模板 | 分类F1、人工拖拽次数 | 高 |
| 接诊 | 数值属于哪个检验项目 | OCR/解析器、单位与范围规则 | 项目-值关联准确率 | 中 |
| 用药 | 药名、剂量、频次、途径的对应关系 | 数值原文复制与单位运算 | 字段及关系F1 | 中 |
| 用药 | 过敏与不良反应描述归类 | 药典、人工审查 | 高风险漏项率 | 中 |
| 用药 | 病历提到的药物是否仍在服用 | 时间线、停药/换药关系 | 药物清单修订时间 | 中 |
| 用药 | 药物不良事件线索筛选 | 候选实体、药学审核 | ADE召回和每例复核成本 | 中 |
| 文书质控 | 规定项目是否记录、缺哪一项 | 专科清单与可引用证据 | 漏项召回、无效提醒率 | 高 |
| 文书质控 | 不同段落矛盾、复制残留 | 患者上下文、数字规则 | 真缺陷发现率与复核时间 | 中 |
| 文书质控 | 自动生成摘要是否漏项/无据添加 | 独立事实金标 | 事实错误检出率 | 中 |
| 文书质控 | 明显医学错误的句子定位 | 医师复核 | 错误召回、定位准确率 | 中 |
| 出院 | 复诊、复查、用药、影像待办提取 | 日期解析、任务系统 | 待办漏项与护士整理时间 | 高 |
| 随访 | 回复是否涉及症状、依从性、失访 | 随访模板 | 人工阅读量与漏升级率 | 高 |
| 随访 | 是否完成指定检查/复诊 | EHR事件对齐 | 待办状态准确率 | 中 |
| 报告 | 放射报告阳性/阴性/不确定标签 | 文本报告输入 | 分标签F1 | 中 |
| 报告 | 临界异常报告需复核的语义线索 | 数值阈值必须代码化 | 漏提醒率、重复提醒率 | 中 |
| 数据治理 | 文档类型、专科、病种标签 | 院内目录 | 分类成本、可检索率 | 高 |
| 数据治理 | 敏感信息候选是否属于PHI | 规则/NER、多层脱敏 | PHI召回，不能只看精确率 | 中 |
| 数据治理 | 重复描述、同义字段、冲突字段 | 去重候选生成 | 合并准确率 | 中 |
| 病案编码 | 文本诊断对应哪些ICD候选 | 检索与多标签选择 | 编码员修订时间、编码F1 | 中 |
| 病案编码 | 编码是否有原文支持 | 证据定位 | 无依据编码检出率 | 中 |
| 科研 | 是否满足研究纳排条件 | 检索、结构化检验规则 | 候选召回、CRC复核时间 | 高 |
| 科研 | 临床试验文本条件分类 | 标签表 | 分类F1 | 高 |
| 科研 | 文献是否符合系统综述纳排标准 | 检索、双人抽查 | 筛查敏感度、筛查工时 | 高 |
| 科研 | PICO和结局候选、证据句定位 | 文档解析与候选片段 | 证据召回与提取时间 | 高 |
| 科研 | 论断是否被给定证据支持 | 可靠来源检索 | 蕴含F1、证据不足识别 | 高 |
| 运营 | 投诉、退费、催报告等工单分流 | 院内业务标签 | 工单错转率与响应时间 | 高但缺公开院内金标 |
| 运营 | 材料是否齐全、转诊理由归类 | 材料清单和院内标准 | 缺件检出率、重复提交次数 | 中 |
| 运营 | 拒付原因文本归类 | 本地支付方原因字典 | 分类F1、复核时间 | 中但缺公开金标 |
| 不优先 | 排班优化、库存预测、死亡风险曲线 | 运筹/统计/时序模型 | 应与专门模型比较 | 不宜强套Jev |
| 不直接适用 | CT/MRI/病理切片、ECG/EEG、原始音频 | 专门视觉/信号/语音模型 | 完整管线单独评估 | 排除原生输入测试 |


## 原先清单之外需要补充的维度

| 维度 | 新增资源或测试 | 仍缺的验证 |
|---|---|---|
| 长病历、跨段落检索 | LongHealth，100题，20个虚构患者 | 真实长病历、跨患者混杂、缺文档版本、时间漂移 |
| 中文计算资料完整性 | CMedCalc-Bench，200条可算/不可算混合 | 精确公式工具、真实缺失模式 |
| 临床等级和评分 | CMedCalc语义分级162条 | 提供院内规则后的独立复测；不等于数值评分计算 |
| 药物相互作用文本关系 | DDI测试集150对 | 真实用药清单与药典规则、患者特异性 |
| 中医 | TCM-SD，148类证型词表，100条测试 | 专家复核、方剂与药物安全；不能外推疗效 |
| 科室推荐 | MedJourney，100条、多标签 | 本院科室映射、紧急程度规则、层级与别名 |
| 护理与交接班 | eICU/DiSCQ资源调查 | 授权原文、护理专属标签和工时 |
| 肿瘤登记和病理 | DeepPhe工具调查 | 登记金标、分期规则版本、跨院验证 |
| 妇产、儿科、老年、精神心理 | 原有语料只覆盖部分 | 按专科分层的独立样本，不能用全局成绩替代 |
| 脱敏、家族史、停药、主体 | 人工挑战样例 | 大规模真实金标、组合情况、漏检成本 |
| 院感、手术记录、输血、康复、营养 | 流程可分解为文本判断 | 当前未取得相应金标，未做任务实测 |
| 护理风险、危急值、急诊分诊 | 仅给定规则的人工例子 | 临床标准、真实人群与前瞻性流程，未验证 |
| 医保拒付、耗材、排班、库存 | 业务文本分类与运筹边界已标明 | 院内标签和优化基线，未测试 |
| OCR/ASR与图像波形 | 明确需外部感知模型 | 本轮没有做原始扫描、音频、医学影像与波形实验 |
| 稳定性 | 少量注入、中英混写挑战 | 重复调用、提示等价改写、不同选项顺序、服务版本漂移 |

覆盖范围以“场景×语料×输入模态×错误类型×真实流程”衡量。找到一个数据集或通过4个人工例子只覆盖其中一小格。不能把名称清单长度当成完成度。
