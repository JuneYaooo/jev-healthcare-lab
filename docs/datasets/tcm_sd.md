## 答案与格式转换

原始 norm_syndrome；不使用病名/证型字段作为输入。

这里只采用可明确计分的判断任务。下方样例是本仓库适配后的评测记录，未将上游原格式冒充为统一请求格式；原始定位与资源链接随样例保留。尚未经过本项目独立医生逐题复核。

### 标准答案与预测格式

原始标注映射后的正确选项键为 `湿热下注证`，对应选项：

```json

```
