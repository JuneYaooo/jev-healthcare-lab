## LabQAR：数值判读

[作者 Figshare v1](https://doi.org/10.6084/m9.figshare.29189894) 的 Set 2 共 550 题，许可 CC-BY-4.0。原数值由作者构造，不能视为真实患者化验数据。与已有“参考区间条件匹配”不同，新任务给出原参考上下界和检验值，考查 High/Normal/Low 判读。

100 条因缺单侧界限、上下界相等或无法解析等原因排除；另 11 条因落在边界、选项不完整或原答案与给定数值关系不符而排除。保留 439 条候选，再抽 100 题。算术只用于筛除不一致记录，答案仍取原选项键。边界约定不清的题不自行补定义；不评价危急程度或临床处理。

## CPIC：药物基因规则

[CPIC 原始许可](https://github.com/cpicpgx/cpic-data/blob/development/LICENSE.md) 明确将整理内容以 CC0-1.0 提供。API 使用方法与字段含义见 [官方文档](https://github.com/cpicpgx/cpic-data/wiki)。本版冻结 2026-10-10 获取的 API v1 原始响应和 SHA-256；该日期是快照日期，不是官方数据库发布版本。原始响应随仓库和开放包提供，重建优先读取并校验快照，避免 API 更新改变旧题。

- **功能表型**：以 `gene_result_lookup.phenotypeid` 连接 `gene_result.id`，输出原始 `result`；输入包含基因、原功能或活性信息，不含结果、解释段落或 EHR 风险优先级。208 条原映射经过冲突去重和基因分组限制后保留 84 题。
- **用药建议**：给定 `drugname`、`population`、`lookupkey`，从同指南、同药物、同人群的原 `drugrecommendation` 文本中选择。不改变建议、不生成干扰处方；相同输入若有不同建议则排除。保留对应指南 URL、推荐强度、原备注和候选原行号。

这两类材料是专家整理的规则，不是病例，也不是临床结局金标。功能题的分组单位是基因，用药建议题是指南；题量和独立规则覆盖量应同时查看。CPIC 内容会更新；临床用途应查看对应指南及更新。候选键随该题候选集合定义，宏 F1 不能当作统一表型或统一临床行动类别指标。

## Evidence Inference：比较试验的报告结果

采用 [Evidence Inference 2.0](https://aclanthology.org/2020.bionlp-1.13/) 的固定仓库版本 `a661e8c14f973398380c8865cf2f27a535aaaf6d`。标注保留仓库 MIT 许可；文章不套用代码许可，逐篇要求原 NXML `permissions/license` 明确链接到 CC-BY。每题保留文章题名、作者、DOI、PMCID、原许可版本及声明；另有[文章署名表](../benchmarks/medical_decision_v1/sources/evidence_inference/article-attribution.md)。

只使用官方测试文章。以 PromptID 连接干预、对照、结局和医生标签；要求全部验证通过的标签一致，且至少一条理由验证通过。排除作者注明错误、存疑或不完整的提示。431 个候选中抽取 100 题，来自 100 篇不同文章。输入是上游处理后的完整文章文本，不提供医生标注的证据片段或答案。

标签为显著升高、显著降低、无显著差异。结局可能是获益也可能是危害，因此“降低”不直接转换为“治疗更好”，无显著差异也不改写成等效。这与已有通用论断支持判断不同：目标限定为原 ICO 比较问题的试验结果方向。

本轮新增的 31 题材料或片段命中过往评测指纹，使总标记数为 577。指纹不代表完整问题必然暴露，也不能排除改写或预训练暴露；训练效果比较应保留该分层。
