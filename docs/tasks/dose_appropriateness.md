## 任务是什么

给定药品规则及患者肝肾功能等，判断剂量是否适宜。

| 项目 | 说明 |
| --- | --- |
| 任务 ID | `dose_appropriateness` |
| 医疗场景 | 治疗与用药 |
| 能力维度 | 资格与适宜性 |
| 决策类型 | 临床候选方案选择 |
| 当前题数 / 目标题数 | 0 / 100 |
| 来源组数 | 0 |
| 语种 | 待补 |
| 数据范围 | 待补 |
