# 辅助与暂停任务

[返回首页](../../README.md) · [临床主评测任务](README.md)

这些任务不计入临床主分数。辅助任务可通过 --scope auxiliary 单独导出和评分；暂停任务仅保留追溯材料。

## 临床计算、解读与证据

| 任务说明 | 题数 | 当前用途 |
| --- | --- | --- |
| [临床量表计算](../tasks/bounded_score.md) | 100 | 计算五种指定量表的分值，有医疗用途，但没有评价评分后应采取的行动；各量表分层报告。 |
| [医疗单位换算判断](../tasks/unit_equivalence.md) | 0 | 通用数值和单位规则能力，不是临床处置；当前为空。 |
| [给定参考表的区间匹配](../tasks/reference_range.md) | 72 | 实际从完整提供的参考表按人群、标本等字段查找答案；不覆盖方法适用性或无法确定类，原名称范围过大。 |
| [长病历事实检索问答](../tasks/long_record_evidence.md) | 100 | 多数目标是从已有文书找到已记录答案，不是根据当时可用资料选择行动；20 个虚构患者须按患者分组。 |
| [病例医学错误检出](../tasks/clinical_error_detection.md) | 100 | 有医疗质量审核意义，但测错误是否存在，非诊疗行动；与错误定位合为一个审核任务的两项指标更合理。 |
| [病例医学错误定位](../tasks/clinical_error_location.md) | 100 | 定位上游注入或标注的错误句，未评价纠正措施；句号位置不是稳定临床类别。 |
| [研究论断与摘要一致性判断](../tasks/claim_support.md) | 100 | 是文献证据判断，不评价指定患者治疗获益；单列证据评估。 |
| [病历论断一致性判断](../tasks/clinical_statement_support.md) | 0 | 判断材料是否支持论断，可作可靠性辅助评测；没有直接诊疗动作，当前为空。 |
| [按给定区间判读检验值高低](../tasks/lab_value_classification.md) | 100 | 有参考区间时进行数值比较，属于检验解读辅助能力，不推断危急值、诊断或处置。 |
| [药物基因功能表型映射](../tasks/pgx_function_phenotype.md) | 84 | 根据已给功能、活性等映射固定规则，非检测全流程或治疗选择；84 题只有 19 个基因来源组。 |
| [试验报告结局方向判读](../tasks/trial_effect_direction.md) | 100 | 判断报告中升高、降低或无显著差异，方向不等于获益，不选择患者治疗方案。 |

## 风险、结局与历史去向预测

| 任务说明 | 题数 | 当前用途 |
| --- | --- | --- |
| [脓毒症发生风险预测](../tasks/deterioration_prediction.md) | 100 | 根据固定前 12 小时预测后续起病，属于风险预测；100 题中阳性 11 题，单看准确率容易误读。 |
| [糖尿病患者回家后 30 天再入院预测](../tasks/readmission_30d.md) | 100 | 只覆盖糖尿病住院后回家人群；100 题仅 7 个阳性，始终预测否即可 93%，不评价是否应入院或何种干预。 |
| [试验人群不良事件发生预测](../tasks/adverse_event_prediction.md) | 0 | 原定义预测试验组事件出现，不是个体患者因果风险或处置；当前为空。 |
| [心衰患者 90 日死亡结局预测](../tasks/mortality_90d.md) | 100 | 仅限心衰基线记录及声明的删失规则；不是普适死亡风险，100 题阳性 22，需报告风险指标与基线。 |
| [术后历史转归去向预测](../tasks/postoperative_disposition.md) | 68 | 金标是过去记录的去向，未证明是最优处置；68 题仅 2 个 ICU 类，不能据此证明 ICU 分流能力。 |
| [孕产记录风险标签分类](../tasks/maternal_risk.md) | 100 | 复制发布方风险等级，不是已观察的母婴结局；需要标签定义核验，单列风险分类。 |
