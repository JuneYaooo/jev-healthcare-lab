## Jev 如何评测

从官方测试集固定哈希抽取 100 条；输入主诉、病情描述和检查，Choice 从 148 个发布证型加 unknown 中选择，对照 norm_syndrome；不发送诊断元数据。

实际模型为 `jev-1.13.0`。100 个 group 是数据源分组标识，不能直接当作独立患者数。

请求仅发送 `sample.request` 中的 `state` 和 `questions`，另添加模型名。`gold` 与 `metadata` 留在本地用于评分，不发送给模型。

### 输入与问题结构

- 输入字段：`chief_complaint, description, detection`。
