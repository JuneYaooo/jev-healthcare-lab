# Jev 与 DeepSeek 同题对比

比较目标是医疗文本中的有限选项判断：效果、成功请求的完整回答等待时间、处理同一批输入的 API 费用。首页面向业务读者，本页保留理解对比所必需的方法和限制。

## 比较的模型与题目

- Jev：`jev-1.13.0`，使用仓库中已核验的真实历史响应。
- DeepSeek：`deepseek-flash`，官方当前对应 **V4.1 Flash**，关闭思考模式，temperature 为 0。服务返回的模型名仍为 `deepseek-flash`，版本名称依据官方映射；旧名 `deepseek-v4-flash` 已不再提供原 V4 Flash。
- 同一批 6,586 条主评测输入、同一组金标、同一组候选和问题。覆盖 72 个公开数据／材料适配任务及 24 类自编挑战，不新增稳定性扰动题。
- 43 条无候选的实体抽取记录，两模型均按同一规则输出空集、不调用 API。空集仍参与原始评分，漏掉的实体仍计入漏检。

型号和模式说明：[官方模型列表与价格](https://api-docs.deepseek.com/quick_start/pricing/)、[思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)。

## 如何做到同题比较

DeepSeek 收到与 Jev 相同的 `state` 和 `questions`，不接收 gold 或评分元数据。额外的系统提示仅说明如何理解问题对象及如何返回 JSON，完整原文见 [config.json](config.json)。

Choice 问题要求返回候选键；NOUL 问题要求逐项给出 true/false。适配器将布尔判断转换为集合筛选所需的 1/0，**这不是 DeepSeek 的概率或置信度**。两者都使用原任务的选择题正确率或严格集合 micro-F1 评分。模型输出接口不同，因此这是相同输入与判断目标的对比，不是两种原生接口完全等价的校准实验。

如果候选键是字符串 `"1"`，模型返回数字 `1`，只做无歧义的键类型转换，不使用金标纠正答案，原始响应保持不变。缺键、越界选项和其他不可解析结果不会被悄悄替换成正确答案。本次仅对网络／格式失败补试一次，旧记录保留在任务的 `comparison/deepseek_attempts.jsonl`；有效但答错的响应不重试。补试后仍失败的输入不从分母中删除：单选记为答错，抽取记为空预测（因此漏掉的金标计入漏检）。最终失败数在首页和统计 JSON 中公开。

## 如何读分数

- **正确率**：答对的记录占比，适用于单选判断。
- **抽取综合分（micro-F1）**：兼顾漏检和误报，以所有记录合计的 TP、FP、FN 计算；首页换算为 0–100 分，不是“多少百分比病例完全正确”。
- 首页“得分更高的任务数”逐任务比较对应指标，只计 72 个公开数据任务，平分单列。没有把不同指标平均，也没有将任务胜负数当作临床总准确率或显著性检验。
- 语音／OCR 对比输入是相同转写或识别文本，两者不直接接收音频／扫描图；上游差异不计作两个模型的差异。

## 如何读耗时

耗时从发送请求开始，到完整响应接收完成为止；不是首字时间或纯模型推理时间。页面显示成功 API 请求中位数，无调用的空候选记录和失败请求不进入该中位数。

Jev 为历史记录，DeepSeek 为新调用，并发为 8。两次运行不是同期、同负载测速；网络、服务负载、上下文长度、输出长度和缓存都可能影响结果。页面可以展示这批实际观察值，不能据此宣称某个模型在所有部署下必然更快。没有把并发批次总耗时和串行单次耗时混用。

## 如何读费用

费用以美元统一比较，按服务返回的实际 token 用量估算：

| 项目 | Jev | DeepSeek 空闲时段 | DeepSeek 高峰时段 |
| --- | ---: | ---: | ---: |
| 每百万未缓存输入 token | $0.042 | $0.15 | $0.30 |
| 每百万缓存输入 token | 同上 | $0.003 | $0.006 |
| 每百万输出 token | 免费 | $0.60 | $1.20 |

[Jev 官方价格](https://docs.typesafe.ai/models) · [DeepSeek 官方价格](https://api-docs.deepseek.com/quick_start/pricing/)

DeepSeek 按各请求提交时所在的官方高峰／空闲时段计价，包含接口报告的实际缓存命中折扣。每条响应保留费率档与原 usage；不能把输入单价直接当成每个病例价格。账号若按人民币扣费，应以其账单和官方人民币价格为准，页面美元数不冒充实际人民币账单。

每千条费用 = 本次可核验 API 费用 ÷ 6,586 × 1,000。Jev 费用来自已留存成功响应；DeepSeek 包含最终响应及留存的可计费重试响应。无法确认费用的断线请求不伪造 token 用量。旧 Jev 的全部失败账单也无法独立核验，所以两者费用均是可核验用量估算，不是完整账单。

费用不包含语音识别、OCR、数据准备、人工复核或业务接入；每条输入也不等于一份完整病历。
